## 3D

| Package | Version | Role |
|---------|---------|------|
| `three` | `^0.185.1` | WebGL — the immersive hero scene (`src/views/home/sections/hero-scene/`) |
| `@types/three` | `^0.185` | Type definitions |

Added 2026-07-26 for the Lando Norris hero rebuild — depth-parallax head,
Draco-compressed helmet GLB, clipped "sliced visor" shards, circuit line art.
As of 2026-08-04 the scene is the GRIDO1 hero: the portrait is `person-*`
maps generated by `scripts/`, and the circuit line art (`tracks.glb`) is no
longer loaded — a procedural backdrop plane replaced it, see [[decisions-log]]
ADR-0021. As of 2026-09-07 the helmet is `helmet3.glb` — a supplied Mercedes-AMG
model carrying its own baked PBR maps as embedded WebP (`EXT_texture_webp`),
which replaced both `helmet.glb` and the whole external livery atlas; see
[[decisions-log]] ADR-0027. (`helmet2.glb` was a first cut of the same export;
it is not committed — `helmet3.glb` superseded it before either was pushed.) It is still the only GLB loaded, and still Draco-
compressed, so the Draco decoder stays.
The Draco decoder is vendored at `public/assets/hero/scene/draco/` (copied from
`three/examples/jsm/libs/draco/`, excluded from ESLint). The render loop rides
the shared ticker via `useLoopInView` — no second rAF. See [[decisions-log]]
ADR-0019 and [[optimize-3d-scene]] for the performance playbook that now
applies to this project. The tier module (`hero-scene/device.ts`) is the
single source for DPR, frame budget, antialias, pointer, the reveal mask's
loop bound and the freeze flag — see [[decisions-log]] ADR-0023.

## Misc

No miscellaneous runtime dependencies. Cookie consent is an in-house component
(`src/components/common/Cookie/`) built on Zustand + `@react-spring/web` — the
former `react-cookie-consent` package was removed. See [[components/common]].
